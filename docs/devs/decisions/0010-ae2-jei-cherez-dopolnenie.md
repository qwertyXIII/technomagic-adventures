# 0010. Перенос рецептов JEI в терминалы AE2 — дополнением, без перехода на EMI

> Обновлено: 2026-10-18

**Статус**: принято

## Контекст

В МЭ-терминале крафта у рецептов JEI не было кнопки «+» (в верстаке была). Причина: AE2 для 1.21 (19.x) не содержит интеграции с JEI — в jar только модули EMI и REI, поэтому JEI не знает, как переложить рецепт в терминал. Второе неудобство: если одни ингредиенты подходят под несколько рецептов, Polymorph даёт выбор в верстаке, но не в терминале AE2.

## Решение

- **AE2 JEI Integration** (Tamaized, mezz; CurseForge 1074338) — возвращает в AE2 поддержку JEI: «+» в терминале крафта и кодирования шаблонов, рецепты машин AE2, перетаскивание призрачных предметов, синхронизация поиска.
- **Polymorphic AE2** (CurseForge 1666854) — кнопка выбора рецепта Polymorph в терминале крафта и кодирования шаблонов. Требует Polymorph (у нас обычный, не Polymorph+; классы API совпадают).
- Оба — `side = "both"`. Связи с JEI 19.64 / AE2 19.2.18 / Polymorph 1.2.0 проверены статически (все классы и методы на месте), сервер стартует чисто; кнопки рисуются только в клиенте — проверены игроками.

## Альтернативы

- Перейти на EMI (AE2 поддерживает его сам) — отвергнуто: игроки привыкли к JEI, а интеграции остальных модов пришлось бы получать через совместимость EMI с плагинами JEI.
- AE2 Utility — отвергнуто: даёт «+», но тянет много лишнего (загрузка шаблонов, дерево рецептов, функции ExtendedAE-Plus).

## Последствия

- При обновлении AE2 или JEI проверять, что AE2 JEI Integration ещё совместим (кнопка «+» в МЭ-терминале крафта).
- Если AE2 вернёт встроенную поддержку JEI — дополнение убрать (иначе два обработчика переноса).
