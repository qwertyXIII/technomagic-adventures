# 0004. Стартовый корабль: шаблон из кода, место — по шуму генератора

> Обновлено: 2026-10-17

**Статус**: принято

## Контекст

Стартовая постройка ставится один раз при создании мира у точки появления. Нужна красивая постройка (корабль с отсеками и шлейфом) на ровном месте, без ручной постройки в игре и с рабочей электрикой.

## Решение

- Шаблон `.nbt` генерирует скрипт сопровождающего (геометрия в коде, превью картинкой); он же пишет блок констант в `kubejs/server_scripts/tm_world.js` (якорь, ключевые позиции, маска подсыпки грунта, блоки питания).
- Место: кандидаты кольцами вокруг точки мира, высоты — `getBaseHeight` генератора (без генерации чанков), штраф за перепад, воду, лес/горы/болото и расстояние; для лучших — точная оценка всех поворотов по отпечатку шаблона.
- Установка — `StructureTemplate.placeInWorld` напрямую: `/place template` при повороте проверяет загрузку не того прямоугольника. После установки — обновление соседей у кабелей и машин; у машины Mekanism в шаблоне явно включён приём энергии (из шаблона она рождается с выключенными сторонами). Ядро ИИ и печь сидят на одной кабельной сети: генератор Powah отдаёт энергию по сторонам по порядку и иначе кормил бы только кабель.

## Альтернативы

- Построить в игре и сохранить структурным блоком — отклонено: правки и сопровождение вслепую, без превью.
- Случайная точка спавна как раньше — отклонено: корабль врезался в склоны и деревья.

## Последствия

При создании мира поиск места занимает 1–6 с. В холмистом мире перепад под кораблём бывает до ~8 блоков (пустоты засыпаются грунтом). Существующие миры корабль не получают.
