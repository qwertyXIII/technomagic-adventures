# 0008. Прокси для ИИ — настройкой в игре

> Обновлено: 2026-10-17

**Статус**: принято. Дополняет [0007](0007-api-neyrosetey-cherez-domashniy-proksi.md).

## Контекст

OpenRouter (поиск «по смыслу», озвучка) недоступен из России напрямую. Обход через DNS роутера ([0007](0007-api-neyrosetey-cherez-domashniy-proksi.md)) пускает через прокси весь трафик ПК хозяина мира, и у подключённых друзей растёт пинг. Нужен прокси только для запросов ИИ, и он должен быть необязательным: без него всё работает как раньше.

У CC: Tweaked есть встроенный прокси (`[http.proxy]` в `computercraft-server.toml` и признак `use_proxy` у правила), но:
- при пустом адресе прокси запрос по правилу с `use_proxy = true` падает («Proxy host not configured»), так что прописать `use_proxy` в конфиге сборки нельзя;
- `config/` перезаписывается при обновлении, адрес своего прокси игрок туда не впишет.

## Решение

- Адрес прокси хранится в данных мира (`tm_proxy`). Задаётся во вкладке «Настройки» ЛОЦМАНа (`proxy`): ЛОЦМАН передаёт его штурманскому модулю, тот выполняет `/tmproxy set …`; оп может вызвать команду сам.
- `kubejs/server_scripts/tm_proxy.js` на лету выставляет поля прокси в `CoreConfig` CC и ставит в начало списка правил два своих правила без действия: `$private` — без прокси, `*` — через прокси. Действие (разрешить/запретить) по-прежнему дают правила конфига. CC читает правила и прокси при каждом запросе, поэтому перезапуск не нужен.
- При запуске мира прокси включается снова; раз в 30 с проверяется, не перечитал ли CC свой конфиг (тогда правила ставятся заново).
- `/tmproxy check <хост>` показывает, как пойдёт запрос: через прокси, напрямую или запрещён.

## Альтернативы

- Прокси в `computercraft-server.toml` вручную на ПК хозяина — отвергнуто: сотрётся обновлением, `use_proxy` без адреса ломает запросы.
- Только домены API нейросетей через прокси — отвергнуто: другой провайдер потребовал бы правки сборки. В интернет из компьютеров ходит практически только ИИ.

## Последствия

- Через прокси идут все запросы компьютеров CC в интернет (в том числе программы игроков), домашняя сеть — напрямую.
- Решение опирается на внутренние поля CC: Tweaked (`CoreConfig.httpRules`, `httpProxy*`). При обновлении CC проверить `/tmproxy check` на тестовом сервере.
