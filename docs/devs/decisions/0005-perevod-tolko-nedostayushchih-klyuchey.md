# 0005. Перевод модов: только недостающие ключи поверх модов

> Обновлено: 2026-10-17

**Статус**: принято

## Контекст

Около трети строк модов сборки не переведены на русский или переведены машинно.

## Решение

Перевод лежит в `kubejs/assets/<namespace>/lang/ru_ru.json` и содержит только ключи, которых нет в `ru_ru` самого мода: KubeJS подключает свои assets поверх модов, а Minecraft сливает lang-файлы по ключам. Терминология — по официальному русскому Minecraft 1.21.1 и общему глоссарию. Исключения, где перевод мода заменён целиком: машинный (Neo Vitae) или битый файл (Immersive Petroleum, Mowzie's Mobs).

## Альтернативы

- Копировать полные `ru_ru` с правками — отклонено: при обновлении мода затираются его новые официальные переводы.

## Последствия

При обновлении мода новые строки остаются английскими, пока их не догонит перевод. Книги Patchouli, руководства AE2/GuideMe и Ponder этим способом не переводятся (не lang-файлы).
