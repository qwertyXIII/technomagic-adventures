Ритуальная магия: духи по договору делают работу.
- Датура (семена из травы) → «видение демона» (отвар): видно скрытые блоки и руды другого мира; очки другого мира дают это постоянно.
- Огонь духов (бросить предмет в огонь духов) превращает предметы: алмаз → самоцвет, настроенный на духа.
- Мел, жертвенные миски (обычные и золотая) и пентакли — ритуалы; книги связывания с именем духа (фолиот → джинн → африт → марид по силе).
- Духи-работники: перенос и сортировка, шахтёры в пространственной шахте (ресурсы без копания), охрана.
- Пространственное хранилище: контроллер хранилища + стабилизаторы — огромное хранилище с поиском; удалённый доступ.
- Айзний — металл другого мира (руда видна в очках, в Незере).
- Боссы-призывы: дикий африт, неукрощённый марид.
В сборке: самоцвет духа нужен МЭ-контроллеру AE2; основа хранилища требует флюисовые кристаллы AE2.
