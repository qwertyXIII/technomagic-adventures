# 0009. ЛОЦМАН — операционная система из приложений

> Обновлено: 2026-10-17

**Статус**: принято

## Контекст

Терминал ЛОЦМАНа вырос из чата с нейросетью в пульт базы: склад, энергия, редстоун, метки, почта, журнал. Если дописывать всё в общие `ui.lua`/`app.lua`, файлы раздуваются, а функции мешают друг другу (и делать их параллельно нельзя). Нейросеть при этом — лишь одна из служб: ключ может не работать, сайт — быть недоступен, а склад и пульт нужны всегда.

## Решение

- Каждая программа — модуль `kubejs/data/computercraft/lua/rom/modules/main/tmai/apps/<id>.lua` по договору из шапки `tmai/apps.lua`: вкладка (строки или свой вид), периодический `tick` в своей корутине, действия в очереди, запросы с КПК (`op="app"`), инструменты для нейросети с префиксом `<id>_`, своё сохраняемое состояние `/tmai/apps/<id>.json`.
- Реестр `tmai.apps` сам находит модули; сломанный модуль не мешает остальным (ошибка — в лог и на вкладку).
- Общие службы — через `ctx`: тревоги `tmai.alert` (лента, КПК, звук; без повторов), операции командного компьютера (`modules/main/tmnav/<id>.lua`, встроенные занять нельзя), ник у терминала, сообщения на КПК.
- Экран: «Главная» (тревоги и все программы), листаемая полоса вкладок, строка ввода для приложений, касания монитора; ПИН-код на «Настройки» (он же закрывает Ctrl+T).
- Учётных записей нет: кто у терминала — по детектору игроков, на КПК — ник КПК.

## Альтернативы

- Одна большая программа — отвергнуто: не масштабируется, нельзя делать частями.
- Отдельные компьютеры под каждую функцию — отвергнуто: игроку нужен один терминал и один монитор; связь и права уже собраны вокруг ЛОЦМАНа.
- Учётные записи игроков — отвергнуто заказчиком: сложность без пользы для игры втроём.

## Последствия

- Новая программа ЛОЦМАНа — новый файл в `tmai/apps/` и офлайн-тест `tools/gen/test_lua_<id>.lua`; общая проверка всех приложений — `tools/gen/test_lua_apps_all.lua`.
- Функции работают без нейросети; нейросеть получает их инструменты и пользуется ими.
