# Как начать играть

> Обновлено: 2026-10-17. Без спойлеров сюжета.

## 1. Установка и обновление
1. Скачайте установщик: **Windows** — [`TechnoMagic-Windows.bat`](https://github.com/qwertyXIII/technomagic-adventures/raw/main/installer/TechnoMagic-Windows.bat), **macOS** — [`TechnoMagic-Mac.command`](https://github.com/qwertyXIII/technomagic-adventures/raw/main/installer/TechnoMagic-Mac.command) (запуск: `bash ~/Downloads/TechnoMagic-Mac.command`).
2. Закройте игру и запустите установщик. Он сам поставит Java 21 (если нужно), NeoForge 21.1.262 и всю сборку (~1 ГБ в первый раз).
3. Появится окно с галочками графики (шейдеры, облака, листва, анимации мобов, звуки):
   - мощный ПК — оставьте всё включённым;
   - слабый ПК / Mac с 8 ГБ — снимите все галочки («лёгкий режим»).
   Поменять выбор позже: `TechnoMagic-Windows-Graphics.bat` / `bash TechnoMagic-Mac.command --graphics`.
4. **Обновление** — тот же установщик ещё раз. Перед обновлением он сам копирует ваши недавние миры в `.minecraft/_world_backups/` (3 последние копии).

## 2. Запуск игры
- В лаунчере версия **`neoforge-21.1.262`** (не Forge, не Fabric, не OptiFine).
- Память игре: **8–10 ГБ** на ПК с 16+ ГБ; **5 ГБ** на Mac с 8 ГБ. Больше 10 не нужно — появятся подтормаживания.
- Язык: Настройки → Язык → Русский. Квесты и всё своё в сборке — на русском; часть модов без перевода останется на английском.
- Первый запуск с таким количеством модов — несколько минут, это нормально.

## 3. Новый мир
- Создавайте **новый мир** (стартовая постройка появляется только в новых мирах). Включите **«Allow Commands: ON»** — пригодится для пункта 4.
- Играть вместе: хозяин мира открывает его для сети, остальные подключаются. Мир живёт, только пока хозяин в игре.
- Голосовой чат — клавиша **V** (Simple Voice Chat), слышно тех, кто рядом.

## 4. Заранее сгенерировать мир (рекомендуется)
Сборка тяжёлая (много модов на ландшафт и постройки): при быстром полёте мир может не успевать прогружаться. Решение — сгенерировать его один раз:
```
/chunky radius 2000
/chunky start
```
- ~40 минут на мощном ПК; мир станет тяжелее примерно на 1–1,5 ГБ.
- Прогресс: `/chunky progress`. Пауза: `/chunky pause`, продолжить: `/chunky continue` (в том числе после перезахода).
- Играть параллельно можно, но возможны подлагивания. Лучше встать в безопасном месте и подождать. В одиночной игре меню паузы (Esc) останавливает и генерацию.

## 5. Бортовой ИИ
В стартовой постройке есть компьютер с бортовым ИИ. Включает **хозяин мира**, один раз на мир:
1. ПКМ по компьютеру под монитором — откроется терминал ИИ.
2. Вкладка **«Настройки»** (щелчок или Tab) → `api_key` → **Enter** → вставить ключ (**Ctrl+V**) → **Enter**.
3. Вкладка **«Чат»**: написать внизу «ты меня слышишь?» и Enter.

Как говорить: **только с терминала или с КПК** — игровой чат ИИ не читает. Кто говорит, терминал определяет сам (детектор игроков); если ошибся — щёлкнуть по имени в строке ввода. Ответ на коды подтверждения — «да 123», остановить программы — «стоп».
- Монитор над терминалом: слева состояние ИИ, справа разделы (чат, задания, память, стройка) — касанием.
- ИИ нужно **питание**: генератор в полу перед терминалом работает на топливе для печи (от него же — электропечь в постройке). Без энергии — «аварийный режим».
- Вдали от постройки — **КПК** и вышки-ретрансляторы (квесты в главе «Бортовой компьютер»).
- ИИ умеет строить черепашкой («прораб»): [как построить дом черепашкой](users/how-to/how-to-postroit-cherepashkoy.md), справка на черепашке — `help tmbuild`.
- ИИ можно перевезти на базу целиком (квест «Переезд»).

Необязательные настройки ИИ (вкладка «Настройки», под каждой — подсказка):
| Что | Настройка |
|---|---|
| Поиск по справочнику «по смыслу» | `emb_key` — ключ OpenRouter |
| Озвучка ответов | `tts` = да (нужен ключ OpenRouter) |
| Лимит действий на один вопрос | `tool_rounds` (0 — без лимита) |
| Длина памяти разговора | `history_chars`, `summary_chars` |

Ключ хранится только в сохранении мира — никуда больше его не пишите.

## 6. Если что-то не так
| Симптом | Что сделать |
|---|---|
| Игра не запускается, ошибка про моды | Запустить установщик ещё раз (докачает недостающее) |
| Вылет при входе в мир | Прислать скриншот/лог сопровождающему (`.minecraft/logs/latest.log`, `crash-reports/`) |
| Дыры в мире при полёте | Пункт 4 (Chunky), дальность прорисовки 12, симуляции 8 |
| ИИ: «ошибка авторизации» | Неверный ключ: «Настройки» → `api_key` |
| ИИ: «помехи, нет связи» | Шлюз ИИ недоступен из сети хозяина мира или модель долго думает — повторить позже |
| ИИ: «аварийный режим» | Нет энергии — заправить генератор |
| ИИ не узнаёт, кто говорит | Вкладка «Устройства» → «Детектор игроков»: если «нет» — в рубке ПКМ два раза по модему под колонкой (справа от терминала) |
| ИИ: поиск «по смыслу» или озвучка не работают | OpenRouter недоступен из сети хозяина мира — нужен обход блокировок на роутере; сборка такой обход пропускает |
| ИИ молчит | Открыть терминал: если программа не работает — `reboot`; лог — `edit /tmai/log.txt` |
| Нужно откатить мир | Копии — в `.minecraft/_world_backups/` (перед обновлениями) и в папке бэкапов мода Simple Backups |
