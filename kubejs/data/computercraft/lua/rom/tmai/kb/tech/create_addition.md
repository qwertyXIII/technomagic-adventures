Create Crafts & Additions связывает Create (вращение, SU) с электричеством остальной техники (FE):
- Электромотор — превращает FE во вращение Create (скорость задаётся в интерфейсе/колесом). Так механизмы Create питаются от генераторов Mekanism, Powah, солнечных панелей.
- Генератор переменного тока (альтернатор) — наоборот, вращение Create → FE. Водяные колёса и паровой двигатель Create могут кормить машины Mekanism и ядро ЛОЦМАНа.
- Прокатный стан (на вращении) — прутки и проволока из слитков; проволока нужна для проводов.
- Коннекторы и провода (медные, золотые) — передача FE на расстояние между столбами.
- Аккумулятор — хранилище FE; зарядная станция — заряжает предметы; катушка Тесла (с депо) — зарядка и «электрическое» зачарование.
- Семенное масло и биотопливо — топливо для горелок и генераторов.

В этой сборке: удобный способ подать энергию FE к ядру ЛОЦМАНа от водяного колеса Create уже на старте (альтернатор + кабель).
