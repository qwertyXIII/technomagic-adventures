Immersive Engineering — промышленность 1940-х: большие многоблочные машины, провода на столбах.

Как собрать мультиблок: построить форму из блоков (смотрите руководство инженера — книга «Engineer's Manual»), ударить молотом инженера по нужному блоку.

Начало:
1. Молот инженера (железо + палка).
2. Коксовая печь (кирпичи коксовой печи из глины, песка и кирпичей): уголь → кокс + креозот. Креозот + доски = обработанное дерево.
3. Доменная печь (огнеупорный кирпич): железо + кокс → сталь. Улучшенная доменная печь (с мехами) быстрее.
4. Энергия: динамо + водяная мельница или ветряк. Провода: медь (LV), электрум (MV), сталь (HV) на коннекторах и реле; трансформаторы между напряжениями; конденсаторы хранят энергию.
5. Верстак инженера — инструменты, улучшения, компоненты; механические компоненты (железный, стальной) — частая деталь.

Большие машины: металлический пресс (пластины, стержни, проволока), дробитель (удвоение руды), дуговая печь (сплавы, переработка лома), экскаватор (бесконечные минеральные жилы), сборщик, бутылкоразливочная машина, соковыжималка и бродильный аппарат (растительное масло, этанол → биодизель через очиститель), дизельный генератор, термоэлектрический генератор, лампы и прожекторы.
Оружие: револьвер (патроны на верстаке инженера), рельсотрон, химический распылитель; щит; турели.

Связи в этой сборке: сталь IE — единая сталь всех модов (Almost Unified). Стальные пластины нужны высекателю AE2, волшебной наковальне Iron's Spells, тиглю Malum, алтарю Neo Vitae, операционной Cyberware. Дюропласт (пластиковая пластина) — для автоматов TACZ. Механические компоненты — для бортового самописца, оружейного верстака, двигателей. Нефть — Immersive Petroleum.
