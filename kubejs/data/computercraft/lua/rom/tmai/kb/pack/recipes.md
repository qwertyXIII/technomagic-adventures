Принцип сборки: крафты немного дороже обычных и связаны между модами — технике нужны магия и трофеи боссов, магии — техника. Всё ниже видно в JEI.

Техника ← магия:
- Металлургический наполнитель Mekanism: вместо редстоуна — исходные самоцветы Ars Nouveau.
- МЭ-контроллер AE2: один флюисовый кристалл заменён самоцветом, настроенным на духа (Occultism).
- Высекатель AE2: вместо железа — стальные пластины.

Техника ← трофеи боссов:
- Элитная схема управления Mekanism: + огненный слиток (Гидра, Сумеречный лес); рецепт даёт 2 схемы.
- Совершенная схема управления Mekanism: + игнитовый слиток (Игнис, Cataclysm); рецепт даёт 2 схемы.
- Контроллер термоядерного реактора: игнитовые слитки вместо стеклянных панелей.
- Антипротонный нуклеосинтезатор: пустотные шипы (босс Пустотный цветок) вместо антиматерии.
- Ядро слияния Draconic Evolution: огненные слитки вместо алмазов.
- Усиленный контроллер Extreme Reactors: урановый стержень Alex's Caves вместо алмазного блока.
- Алтарь пробуждения Mystical Agriculture: древняя душа (Ночной лич, BOMD) вместо оранжевой шерсти.

Магия ← техника:
- Чародейский аппарат Ars Nouveau: латунь Create вместо золота.
- Волшебная наковальня Iron's Spells: стальные пластины.
- Тигель духов Malum: + 4 стальные пластины IE в настой.
- Печь кальцинации Theurgy: латунь вместо железа.
- Ara Vitae (алтарь Neo Vitae): стальные пластины вместо золота.
- Основа хранилища Occultism: флюисовые кристаллы AE2 вместо меди.

Импланты и прочее:
- Операционная Cyberware: стальные пластины и базовая схема Mekanism; кибер-верстак — сталь и печатная плата IE.
- Репликатор: совершенная схема Mekanism.
- Оружейный верстак TACZ: сталь и стальной механический компонент IE. Огнестрел: железо заменено сталью (вдвое меньше), лазурит — пластиком (дюропласт IE из нефтехимии), тяжёлое оружие — плюс механизм точности Create.

Космос и транспорт:
- Верстак НАСА Ad Astra: продвинутые схемы Mekanism вместо факелов.
- Двигатели ракет: стальной — поршни двигателя Create Diesel Generators; двигатель из деша — армированный сплав Mekanism; острумовый — огненные слитки; калоритовый — ядро Виверны Draconic.
- Двигатель Immersive Aircraft — поршни двигателя Create Diesel Generators.
- Ракетное топливо — только из керосина (см. «Нефть и топливо»).

Связь: эндер-модем CC: Tweaked — поздний (дыхание дракона, сингулярности квантовой запутанности AE2, ядро Виверны).

Энергия: Solar Flux — панели V–VIII собираются по новым рецептам (блок исходных самоцветов, фотоэлементы Ad Astra, совершенные схемы, ядро Виверны); панели «нейтрониевая» и «бесконечная» для AvaritiaNeo — на экстремальном верстаке.

AvaritiaNeo (эндгейм без многочасового гринда): экстремальный верстак требует пробуждённые ядра Draconic; нейтронный коллектор — гранулы антиматерии, работает в ~6 раз быстрее; сингулярности вдвое дешевле; катализатор бесконечности — только через Сингулярность бесконечности, а в неё входят трофеи девяти боссов: игнитовый, проклятый, визеритовый слитки и слиток из древнего металла (Cataclysm), древняя душа и пустотный шип (BOMD), трофеи Древнего гаста и Снежной королевы (Сумеречный лес), «Лик солнца» Умвути (sol_visage) (Mowzie's Mobs).
