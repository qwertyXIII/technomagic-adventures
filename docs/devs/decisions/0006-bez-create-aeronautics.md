# 0006. Без Create Aeronautics

> Обновлено: 2026-10-17

**Статус**: принято (повторно подтверждено 2026-10-17)

## Контекст

Create Aeronautics (летающие постройки на физике Sable) есть под NeoForge 1.21.1. Блоки на корабле остаются настоящими (машины работают в полёте), но мод тяжелее Create, есть риск с Sodium/Iris/C2ME, а у блоков корабля «внутренние» координаты — расчёты ИИ по позиции (зона связи, вышки) потребуют доработки. Ядро ИИ и штурманский модуль неразрушимые и в такой корабль не попадут без переноса.

## Решение

Не добавлять. Движущиеся постройки — штатными средствами Create (подшипники, поршни, поезда).

## Альтернативы

- Добавить экспериментально и проверить в живой игре — отложено (roadmap → Later).

## Последствия

Летать — на самолётах Immersive Aircraft и ракетах Ad Astra.
