- Память: хосту — 8 ГБ для игры (в лаунчере), на Mac с 8 ГБ ОЗУ — 5 ГБ.
- Шейдеры: на слабом компьютере — MakeUp Ultra Fast или без шейдеров; Complementary — для сильных.
- Новые чанки генерируются медленно (много структур). Хосту полезно заранее сгенерировать мир вокруг базы: /chunky radius 1500, затем /chunky start (можно оставить на ночь).
- Дальность прорисовки 8–10, симуляции 6–8.
- Не прогружайте лишние чанки и не стройте огромные фермы мобов: нагрузка общая для всех через хоста.
