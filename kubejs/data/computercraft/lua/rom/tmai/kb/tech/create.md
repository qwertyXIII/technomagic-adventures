Create — техника на вращении (единицы нагрузки SU), без электричества.

Начало:
1. Андезитовый сплав (андезит + железные самородки/цинк) — основа корпусов, валов, шестерён.
2. Источник вращения: водяное колесо (у текущей воды), подшипник ветряной мельницы с парусами, позже паровой двигатель (бак жидкости + горелка всполоха) и дизельные двигатели (Create Diesel Generators).
3. Валы, шестерни, ремни передают вращение; очки инженера показывают скорость и нагрузку. Большие шестерни меняют скорость.

Ключевые машины:
- Жёрнов, дробильные колёса — дробление руды в дроблёную руду (больше слитков), гравий, мука.
- Механический пресс + чаша — сжатие (листы из слитков); смешиватель + чаша — смешивание (сплавы, бетон). Горелка всполоха под чашей даёт нагрев (латунь = медь + цинк с нагревом).
- Вентилятор в корпусе: поток через воду — промывка (дроблёная руда → самородки и бонусы), через лаву/огонь — плавка и копчение, через душевой огонь — призрачность.
- Ремни, депо, механическая рука — сортировка и подача. Автономный активатор (деплоер) работает как игрок (ставит, использует предметы). Механический сборщик — автокрафт больших рецептов.
- Последовательная сборка — многошаговые рецепты на ремне (механизм точности, сигнальные блоки).
- Поезда: рельсы, станции, расписания — транспорт ресурсов на большие расстояния.

Связи в этой сборке:
- Латунь Create нужна чародейскому аппарату Ars Nouveau и печи кальцинации Theurgy.
- Механизм точности нужен тяжёлому оружию TACZ; электронные лампы и андезитовый сплав — для починки бортового самописца капсулы.
- Поршни двигателя Create Diesel Generators нужны двигателям самолётов и стальному двигателю ракеты Ad Astra.
- Горелка всполоха требует всполоха из Незера.
