# 0003. Кириллица в CC: Tweaked — свой шрифт по схеме CP1251

> Обновлено: 2026-10-17

**Статус**: принято

## Контекст

Терминал CC хранит символы байтами 0–255 и рисует их глифами текстуры `term_font.png`; кириллицы в ней нет, поэтому экраны ИИ и КПК были на транслите. С клавиатуры CC 1.120 кириллицу не пропускает вовсе: событие `char` для неё не приходит, вставка из буфера её отбрасывает.

## Решение

Текстура шрифта подменяется через `kubejs/assets/computercraft/textures/gui/term_font.png`: русские буквы рисуются в слотах латинских букв с диакритикой по схеме CP1251 (А..я — 0xC0..0xFF, Ё/ё — 0xA8/0xB8, № — 0xB9). Программы переводят UTF-8 в байты модулем `tmai.text`, справки CC хранятся в CP1251. Ввод — редактор `tmai.input`: русская буква восстанавливается по физической клавише ЙЦУКЕН (событие `key` приходит при любой раскладке).

## Альтернативы

- Транслит — отклонено: плохо читается, ИИ отвечает длинными текстами.
- Отдельный мод-шрифт или правка CC — отклонено: под 1.21.1 нет, свой мод сопровождать дороже.

## Последствия

Латинские буквы с диакритикой (é, ü…) на экранах CC недоступны. Вставка русского текста из буфера в CC невозможна (ключи API и адреса вставляются). Всё, что программы печатают по-русски, должно идти через `text.cc`.
