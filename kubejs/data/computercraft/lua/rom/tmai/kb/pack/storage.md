Приложение «Склад» — вкладка терминала капсулы (и монитора). Работает и без нейросети; ты управляешь им инструментами storage_*. Подключение блоков — раздел pack.storage_setup, переплавка и конвейеры — pack.storage_smelt.

СКЛАД = все сундуки, бочки, ящики модов в проводной сети компьютера ЛОЦМАНа + МЭ-сеть (через ME Bridge). Не склад: ядро ИИ, Ящик памяти, «Выдача», «Приёмка», сундуки конвейеров, печи, машины. Индекс обновляется сам каждые ~30 с.

СУНДУКИ: НОМЕРА И ИМЕНА. У каждого сундука номер (№7). Игрок может дать имя («руды», «из печи») — только через ЛОЦМАНа: storage_name_chest или вкладка «Склад» → «Источники» → Enter. Имя с наковальни CC НЕ видит — так и скажи и предложи назвать через тебя. Во всех инструментах сундук можно указать: имя, номер («7»), «новый» (последний подключённый), «пустой», «где лежит X».
Неоднозначно (два новых, несколько пустых, X в нескольких сундуках) — инструмент вернёт need_choice: переспроси игрока, перечислив варианты (номер, имя, что лежит), и повтори с номером. storage_chests — список всех: num, name, роль, заполненность, top (что лежит), new.

ИНСТРУМЕНТЫ
- storage_find(query) — сундуки И МЭ (me_find — только МЭ). where: «МЭ 500; руды 120; №3 40».
- storage_take(item, count) — в сундук «Выдача» тому, кто спросил (до 4096). Ответ text — перескажи. missing + craftable — предложи me_craft; крупный заказ даёт код — игрок пишет «да КОД».
- storage_watch(item, min) — тревога, когда меньше min; снимется сама. min=0 — убрать; без item — список.
- storage_chests(), storage_name_chest(chest, name?, role?) — имя (name="" — убрать) и/или роль: issue — «Выдача», intake — «Приёмка», misc — «Разное».
- storage_sort_rule(action=add|remove|list, what, to, n) — правило «что → куда».
- storage_sort_now(chest?) — разложить сейчас «Приёмку» или указанный сундук.

СОРТИРОВКА. Сундук «Приёмка» (вкладка «Склад» → «Сортировка» или storage_name_chest(chest, role="intake")): всё, что туда кладут, ЛОЦМАН сам раскладывает порциями: 1) по правилу; 2) в сундук, где этот предмет уже лежит; 3) в МЭ, если включено «Лишнее — в МЭ»; 4) в сундук «Разное». Не удалось — остаётся в «Приёмке», тревога. «Разобрать сундук» — то же для любого сундука (storage_sort_now chest=…).
«Что» в правиле: предмет (название или ID), мод («create:»), тег («#c:ingots»), категория: руды (руда и сырьё), слитки, самоцветы, пыль, блоки ресурсов, еда, семена, урожай, саженцы, дерево, камень, песок, блоки, инструменты, оружие, броня, зелья, красители, с мобов. Несколько правил подходят — точный предмет важнее тега, тег — категории, категория — мода. «Куда»: имя или номер сундука, «МЭ».

ПРИМЕРЫ ФРАЗ → ДЕЙСТВИЯ
- «Назови новый сундук "слитки"» → storage_name_chest(chest="новый", name="слитки").
- «В сундук 5 складывай все слитки» → storage_sort_rule(add, what="слитки", to="5"). Если «Приёмка» не выбрана — скажи: правило работает для «Приёмки» (выбрать на вкладке «Склад» → «Сортировка») и при «разложи сундук N».
- «Еду — в сундук, где хлеб» → storage_sort_rule(add, what="еда", to="где лежит хлеб").
- «Всё из create — в МЭ» → storage_sort_rule(add, what="create:", to="МЭ").
- «Разбери сундук 12» → storage_sort_now(chest="12").
- «Новый сундук пусть будет приёмкой» → storage_name_chest(chest="новый", name="приёмка", role="intake").
- «Где алмазы?» → storage_find("алмаз"). «Дай 32 угля» → storage_take(minecraft:coal, 32).
- «Следи, чтобы железа было не меньше 64» → storage_watch("железный слиток", 64).

ЕСЛИ НЕ ТАК
- «не выбран сундук «Выдача»» — выбрать на вкладке «Склад» → «Выдача».
- «сундуки не видят друг друга» / «МЭ-мост не видит» — сундук стоит вплотную к компьютеру или в другой сети: поставить на проводной модем в общую сеть (pack.storage_setup).
- Предмет посчитан дважды — сундук подключён к МЭ шиной хранения: исключить его в «Источниках» (Delete).
- Сундука нет в списке — модем не включён (ПКМ по модему) или оборван кабель.
