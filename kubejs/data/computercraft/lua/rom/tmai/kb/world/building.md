Моды для красивой базы:
- Macaw's Doors / Windows / Roofs / Bridges — десятки дверей (в т.ч. сарайные, японские, стеклянные), окон и ставней, крыши всех форм из любых пород дерева и камня (скаты, коньки, слуховые окна), мосты и лестницы. Крафт на верстаке; многие блоки меняют форму ПКМ.
- Handcrafted — мебель: стулья, столы, диваны, кровати с балдахином, шкафы, полки, тарелки, чашки; дерево любой породы.
- Chipped — сотни вариантов обычных блоков (камень, дерево, стекло, шерсть, фонари). Нужны мастерские Chipped (каменщика, плотника, стекольщика, ткача и др.): положить блок — выбрать вариант.
- Framed Blocks — «рамочные» блоки любой формы (склоны, углы, тонкие стены, колонны), в которые вставляется любой блок как облицовка (ПКМ блоком по рамке). Молоток Framed Blocks убирает облицовку.
- Create Deco — кирпичи разных цветов, металлические листы, решётки, лампы, люки и двери в индустриальном стиле Create.
- Ещё раньше в сборке: Supplementaries (банки, указатели, фонари, флюгеры), Quark (вертикальные плиты, варианты дерева, сортировка инвентаря), Valhelsia Furniture.

Строить помогает ЛОЦМАН: «прораб» строит черепашкой по плану (раздел о стройке).
